# Domain context

## Glossary

### Неизвестный порт

Доступный последовательный порт, для которого не определена модель подключённой платы.

### Профиль платы

Описание модели платы и параметров загрузки прошивки для неё. Несколько физических плат могут использовать один профиль.

### Ручное назначение платы

Выбор пользователем профиля для конкретного подключённого устройства, имеющий приоритет над автоматическим определением.
